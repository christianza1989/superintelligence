# Atviras kandidatų registras

**806 adresų patikros, 757 unikalūs prieinami GitHub repo, 796 registro įrašų su neišspręstais adresais.** Katalogo dydžio ribos nėra. Kiekvienas tyrimo ciklas turi baigtinį laiko / užklausų biudžetą; tai nėra bendro kandidatų skaičiaus kvota.

Pirmasis [100 projektų palyginimas](TOP100.md) išsaugotas kaip istorinė imtis. Nauji kandidatai negauna išgalvotų balų. Visi runtime `NOT_RUN`, nė vienas naujas įrašas savaime netampa integracija ar recommended moduliu. Šaltinio kodo viešumas nėra open-source licencijos patvirtinimas. Trūkstama / ribojanti licencija, modelių teisės ir archyvavimas lieka matomi.

Duomenys: [JSON](../../catalog/candidates.json), [CSV](../../catalog/candidates.csv), [tikslūs SHA, failų hash ir laikai](../../catalog/evidence.json), [skaičiavimo apimtis](../../catalog/research-run.json). Pirminio šaltinio perskaitymas ir source-only būsena nėra runtime kokybės vertinimas.

Atranka vėliau: konkretus gebėjimas → alternatyvų / dubliavimo palyginimas → code/weights/data licencijos → kilmė ir pin → izoliuotas build → conformance ir realios užduotys → kokybė / p50,p95 / kaina / CPU,RAM,VRAM,diskas → gedimai ir atnaujinimai → rekomendacija konkrečiai versijai ir OS. Stars ir Trending padeda atrasti; neprivalomi priėmimui.
